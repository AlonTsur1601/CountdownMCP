# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's security advisory feature. Do not open a public issue containing an exploit, credentials, authentication data, private session content, or private rate-limit metadata.

CountdownMCP reads rate-limit information through the local Codex app-server and a constrained local fallback. It does not expose account tokens, conversation content, or another MCP server's state.
